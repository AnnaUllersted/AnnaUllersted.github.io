A personal project, built from scratch in collaboration with my brother: an online tool that turns any uploaded image into a knitting pattern, generated to your own gauge and needle setup.

## What it does

Upload an image of a motif, set your desired height, stitch and row gauge, knitting method (e.g. in the round), and where the work starts, and the tool generates a matching knitting pattern — no manual charting required.

## Tools

Python (server) · JavaScript · HTML & CSS
